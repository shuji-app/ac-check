# エアコン点検アプリ — GitHub Pagesで公開してiPad/Edgeから使う方法

## 必要なファイル（この2つをアップロードすればOK）
- `index.html`
- `app.compiled.js`　←アプリ本体（あらかじめJSXをプレーンなJavaScriptに変換済み）

`app.jsx`（元のJSXファイル）は編集用の元データとして同梱していますが、
**そのままではブラウザは読めません**。今回「読み込み中のまま動かない」問題への対策として、
ブラウザ上でその場にJSXを変換する方式（Babel Standalone）をやめ、
事前にプレーンなJavaScript（`app.compiled.js`）に変換したものを使う方式に変更しました。
理由：Babel Standalone方式は、ネットワークやブラウザによっては変換に時間がかかったり、
CDNの読み込みが失敗して「読み込み中」のまま止まってしまうことがあったためです。

---

## 手順（GitHub Pages）

1. **GitHubで新しいリポジトリを作る**（Public）
2. **`index.html` と `app.compiled.js` をアップロード**
   - リポジトリ画面→「Add file」→「Upload files」→ドラッグ＆ドロップ→Commit
   - ※ `app.jsx` は無くても動きます（アップロードしなくてOK。編集したくなったときのための控えです）
3. **Settings → Pages で公開設定**
   - Source: 「Deploy from a branch」／ Branch: `main` ／ フォルダ: `/ (root)` → Save
   - 1〜2分待つと公開URLが表示されます（例：`https://ユーザー名.github.io/リポジトリ名/`）
4. **iPad・EdgeでそのURLを開く**

## それでも「読み込み中」のまま動かない場合の確認ポイント

1. **ファイル名・配置場所が合っているか**
   `index.html`と`app.compiled.js`が**同じ階層（フォルダ）**に置かれているか確認してください
   （サブフォルダに分けていると読み込めません）。

2. **ブラウザのキャッシュを疑う**
   一度読み込みに失敗した状態がキャッシュされている場合があります。
   URLの末尾に `?v=2` のように適当な文字列を付けて再読み込みしてみてください
   （例：`https://ユーザー名.github.io/リポジトリ名/?v=2`）。

3. **開発者ツールでエラーを確認する**
   - Windows/Edge：F12キー→「コンソール」タブに赤字のエラーが出ていないか確認
   - iPad：Macがあれば「設定→Safari→詳細→Webインスペクタ」をiPad側でオンにし、
     MacのSafari「開発」メニューからiPadの画面を検証できます。Macが無い場合は、
     まず**同じURLをPCのEdge/Chromeで開いて動くか**を先に確認してください
     （PCで動けばコードの問題ではなく、iPad側のネットワーク・設定の問題の可能性が高いです）。

4. **社内ネットワーク・フィルタリングで海外CDNがブロックされていないか**
   `index.html`は`cdnjs.cloudflare.com`からReact本体を読み込んでいます。
   会社や学校のWi-Fiでこのドメインがブロックされていると、読み込みが止まります。
   一度、スマホのモバイル回線（Wi-Fiを切る）で同じURLを開いて動くか試してみてください。
   これで動く場合は、Wi-Fi側のフィルタリングが原因です。

5. **8秒たっても終わらない場合、画面に赤文字でヒントが出るようにしてあります**
   `index.html`に、読み込みが遅いときに簡単なメッセージを出す仕組みを入れています。
   それが出た場合は、上記3・4を確認してください。

## データ（点検記録・機器リストなど）について、重要な注意

このアプリは**ブラウザのlocalStorageにデータを保存**しています。

- **iPadとEdge（Windows）はデータが同期されません。** それぞれ別々の保存領域です。
  同じiPadでも「Safari」と「Chrome」は別々に保存されます（アプリではなく、ブラウザ単位の保存）。
- 同じiPadの同じSafariなら、次に開いたときも点検データは残っています（ページを閉じても消えません）。
- ブラウザの「閲覧履歴とWebサイトデータを消去」をすると、保存されている点検データも一緒に消えます。
- 複数端末でデータをまとめたい場合、今の作りでは自動同期されないため、
  「データ一覧」画面のCSV出力機能で集約する運用が現実的です。

## 動作環境について
- iPad：Safariで動作します。
- Windows：Microsoft Edge・Google Chromeどちらでも動作します。
- オフラインでは動きません（React本体をCDNから読み込むため、初回は必ずインターネット接続が必要です）。

## 今後app.jsxを編集した場合
編集後、以下のコマンドで`app.compiled.js`を作り直してから再アップロードしてください
（Node.jsと`@babel/core`・`@babel/preset-react`が必要です）。
